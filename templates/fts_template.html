Method. All figures on this page are based on reports to the password-protected lot checking data collector form. If your lab wants to participate, contact Prof. Lieberman. A lot is identified by Brand + Lot number; expiration dates are recorded but not used for matching, since testers occasionally mistype them. “Fentanyl detection rate” pools every individual strip run at 200 ng/mL across all submissions for that lot; “true negative” pools every strip run in plain water. Interferents are flagged when any replicate at any tested concentration (2.0, 0.7, or 0.2 mg/mL) read positive. Some recently-logged lots show “—” because no replicates have been run yet. Thumbnails and gallery photos use the first image from each submission's product/packaging upload (column M); this is a static prototype, so photos are a fixed snapshot and refresh is manual for now.
