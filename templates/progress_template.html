Lot checking progress tracker

Which test-strip lots are in the lab and how much testing each one still needs.

Method. "Complete" means testing coverage, not that the lot passed — a lot with a confirmed, fully-characterized interference still counts as complete. A lot is "complete" when every listed target has ≥25 recorded detection runs, the true-negative-with-water check has ≥5 runs, every listed interference substance has been run at 2 mg/mL (and, if positive there, also run at 0.7 or 0.2 mg/mL), and at least one packaging photo and one strip photo are on file. Run counts and photo counts are read directly from the FTS/XTS dashboards' own computed data, not re-derived from the raw sheets. "In lab" status and received-date come from the lot intake form; a lot with real test submissions but no logged intake row still appears here (most lots will look like this until students log them retroactively). Strip types without a completion checklist yet (no build script exists) show as "not yet supported" rather than complete or incomplete.
